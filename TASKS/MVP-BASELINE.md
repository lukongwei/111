# Task: Full-Chain MVP Baseline

## 目标

在不引入 LLM 作为核心依赖的前提下，把 Index 到 Gateway、Context、Adapter、Dashboard、Audit 和 Maintenance 的最小可运行链路接通。

## 已完成

- [x] FTS5 Name / Path / Text / Metadata Search。
- [x] Python AST Class / Function Symbol Index。
- [x] imports / calls / tests / contains 基础 Relation。
- [x] Gateway 请求验证、项目隔离、敏感文件保护、Context Budget、操作审计。
- [x] Context Engine 渐进式检索和受限读取。
- [x] 模型无关 Agent Adapter。
- [x] 中央 Dashboard JSON HTTP API。
- [x] Operation / Decision / Change / Token Audit。
- [x] 确定性 Maintenance 健康检查。
- [x] 全量自动化测试和跨模块契约测试。

## 明确后续增强

多语言 AST、完整静态调用分析、Git History / rename、文档冲突和 Token 异常检测、Dashboard 前端、多进程写入协调、数据库迁移工具和真实 LLM Provider Adapter。
